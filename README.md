# 🏢 Employee Leave Management System (ELMS)

A modern web application for managing employee leave requests, approvals, leave balances, and team availability.

## ✨ Features

### Employee

* Submit leave requests
* View leave balances
* Track request status
* View leave calendar
* Receive manager feedback

### Manager

* Approve or reject requests
* View all employee leaves
* Manage leave balances
* Access team calendar
* Monitor leave activities

### Admin Panel

* User Management
* Leave Type Management
* Leave Balance Management
* System Statistics & Analytics
